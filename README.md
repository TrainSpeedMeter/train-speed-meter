# Train Speed Meter

Official repository for **Train Speed Meter** — a simple and fast web tool to check live Indian Railways train speeds and GPS locations in real-time on mobile browsers.

## Key Features
- Live GPS Speedometer for Indian Trains.
- No app installation required (runs directly in mobile browsers).
- Battery-efficient and lightweight live tracking interface.

Check your live train speed now: [Train Speed Meter](https://trainspeedmeter.com)
